# Single-tutorial illustration: Illustrator loop-border tutorial

Source: user-provided public Bilibili page, “AI 制作回形纹路,” BV1BbHieLERk: https://www.bilibili.com/video/BV1BbHieLERk/

The included CSV is a normalized copy of the user's frame-screening log. It records 50 candidate sample timestamps from 0.85 s to 50.54 s and 17 manually retained stages. This gives 17/50 = 34% retained and a 66% reduction among those candidate timestamps.

The word “candidate” is intentional: the log does not document every decoded source frame. It also does not contain the source video, the 33 discarded candidate images, an audio track, a time-coded ASR transcript, model prompts, or model answers. The case therefore cannot measure frame recall, knowledge accuracy, transcription quality, or learning gains. It only documents one human-curated frame-selection trace.
